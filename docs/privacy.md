# プライバシーポリシー — PC 健康診断（PcReport）

最終更新：2026-10-06 ／ 提供：MicroForge（開発者：33）

## 1. 要点

**このアプリは、通信を一切行いません。** 収集した情報は、この PC の中だけで処理され、外部に送信されることはありません。開発者を含む第三者が、利用者の情報を受け取ることはありません。

## 2. このアプリが読み取る情報

PC の状態をまとめたレポートを作るために、次の情報を Windows から読み取ります。

- Windows の版・ビルド・エディション、最後に起動した日時、更新プログラムの適用状況
- ウイルス対策ソフトの有効／無効と定義ファイルの更新日
- CPU の名称とコア数、メモリの容量と空き、ディスクの容量と空き
- 起動ドライブの種類（SSD / HDD）と型番、ディスクの健康状態、詳細な状態値（温度・使用時間など。管理者権限がある場合）
- TPM とセキュア ブートの状態（Windows 11 の要件確認のため）

## 3. レポートに含めない情報

設計として、次の情報は**取得も表示もしません**。

- Windows のユーザー名、PC 名（コンピューター名）
- IP アドレス、MAC アドレス
- ディスク・BIOS・マザーボードのシリアル番号
- ファイルの中身、閲覧履歴、入力内容

## 4. 情報の保存

レポートは **HTML ファイル 1 つ**として、この PC の中に保存されます。保存先は、**アプリの場所 → デスクトップ → ダウンロード → アプリ専用のフォルダ → 一時フォルダ**の順に試し、保存できた場所に書き込みます（ウイルス対策ソフトのフォルダ保護などで書き込めないことがあるため）。アプリの場所以外に保存したときは、保存した場所をお知らせします。保存したファイルの扱いは利用者に委ねられます。

アプリは、レポート以外のファイルを作りません。設定ファイルや利用履歴も保存しません。

## 5. 第三者への提供

ありません。通信しないため、提供する経路そのものがありません。

## 6. 解析・広告

解析（テレメトリ）も広告も含みません。

## 7. 子どもの情報

特に子どもを対象としたアプリではなく、個人を識別する情報を収集しません。

## 8. 変更

このポリシーを変更する場合は、このページの最終更新日を改めます。
