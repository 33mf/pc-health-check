# PC 健康診断

提供：MicroForge

ダブルクリックするだけで、この PC の健康診断の結果を 1 枚の HTML にまとめます。通信しません。人に送れる形で残せます。

離れて暮らす家族の PC を見るときなどに、「今どうなっているか」を 1 枚にまとめて渡せます。

## 調べること

- Windows の版と、更新プログラムが最後に入った日
- ウイルス対策ソフトが有効か、定義ファイルは新しいか
- CPU・メモリ・ディスクの空き
- 起動ドライブが SSD か HDD か
- ディスクの健康状態
- Windows 11 に上げるための条件（TPM・セキュア ブート・CPU）

## このツールの考え方

- **通信しません。** 集めた情報はこの PC の中だけで処理され、どこにも送られません
- **ユーザー名・PC 名・IP アドレス・シリアル番号は載せません。** そのまま人に送れる形にするためです
- **取れなかった項目は消しません。** 「取得できませんでした（理由）」と書きます
- **設定画面はありません。** 管理者権限も要求しません
